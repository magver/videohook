# ТЕХНИЧЕСКИЙ ОТЧЕТ: АРХИТЕКТУРА И СОСТОЯНИЕ ПРОЕКТА VIDEOHOOK

## 1. Стек и Платформа
- **Тип приложения**: Десктопное приложение для Windows (чистый Python 3.10+, упаковывается в standalone .exe через PyInstaller).
- **GUI-фреймворк**: CustomTkinter >= 6.0.0 (современная темная тема поверх Tkinter) + 	kinter.Canvas для интерактивного таймлайна с полосами нарезки.
- **Видеодвижок и кадры**: OpenCV (cv2) для декодирования, анализа салиентности (Smart Crop) и покадрового отображения; Pillow (PIL) для отрисовки в UI.
- **Аудиодвижок**: pygame.mixer для синхронного предпрослушивания звука при скраббинге и воспроизведении видео в окне редактора.
- **Рендер / Кодирование**: FFmpeg (прямой вызов через subprocess, автопоиск бинарника в системе, бандле или через imageio-ffmpeg).
- **Сетевой слой и парсинг**: yt-dlp (поиск и выкачивание роликов с YouTube в 1080p), equests (AniList GraphQL API).

## 3. Как ищет интересные моменты

1. **База знаний + AniList API (	rends.py)**:
   - Через GraphQL-запрос к AniList подтягиваются текущие тренды и топ аниме.
   - По словарю ICONIC_MOMENTS_DB извлекаются точные культовые эпизоды и сцены (бои, признания, ключевые моменты).
   - К каждому моменту привязаны точный поисковый запрос (русская озвучка / субтитры), цепляющий заголовок-хук и цитата.
   - Для неизвестных тайтлов генерируются запросы по жанрам и популярным тегам.
2. **Аудиоанализ пиков для локальных файлов (nalyzer.py)**:
   - Из видео извлекается легковесный моно PCM-поток (8 kHz).
   - Вычисляется RMS (Root Mean Square) энергия звука в скользящем окне 15–30 сек.
   - Исключаются опенинги (первые 90 с) и эндинги (последние 90 с).
   - С помощью Non-Maximum Suppression (NMS) отбираются топ-N неколлидирующих пиков с интервалом не менее 45 секунд.

## 4. Как выглядит редактор (editor_window.py)

Модальное окно редактора (размер 1220x900):
- **Левая колонка**:
  - Окно видеопревью на OpenCV + pygame.mixer (с кнопкой звука и индикатором времени).
  - Слайдер перемотки (Scrubber) с шагом до десятых долей секунды.
  - Панель управления воспроизведением (▶ Воспроизвести, ⏪ -1с, +1с ⏩, 🔊 Звук).
  - Панель инструментов ножниц:
    - Кнопка «✂️ Режим ножниц: ВКЛ/ВЫКЛ» (позволяет резать кликом прямо по полосе).
    - Кнопка «✂️ РАЗРЕЗАТЬ ЗДЕСЬ» (горячие клавиши S или Ctrl+K).
    - Кнопка «↩ Отменить разрез» (Ctrl+Z).
    - Кнопка «↺ Сбросить всё».
  - Раскадровка (Filmstrip): горизонтальная лента с превью кадров каждые 3–5 секунд.
  - Интерактивный таймлайн на 	k.Canvas (зеленые сегменты — «оставить», красные — «вырезать», красный бегунок плейхеда).
- **Правая колонка**:
  - Список отрезков со статусом «Оставить» / «Вырезать» и точными таймкодами.
  - Модуль **Smart Crop 9:16** с кнопкой запуска анализа персонажа.
  - Оформление: выбор **Fullscreen** / **Blurscreen**, поле ввода субтитров, выбор фонового трека (Phonk, Epic, Lo-Fi, свой файл), громкость музыки, хук-заголовок, водяной знак.
  - Кнопка запуска финального экспорта с прогресс-баром.

## 5. Pipeline Рендера (clipper.py и smart_crop.py)

Рендеринг выполняется полностью на **FFmpeg** без перекодирования сторонними библиотеками:
1. **Обрезка и склейка**: выбранные сегменты нарезаются фильтрами 	rim / trim и склеиваются фильтром concat=n=N:v=1:a=1.
2. **Геометрия 9:16 (1080x1920)**:
   - *Fullscreen*: кроп по центру или по координатам Smart Crop.
   - *Blurscreen*: фон блюрится через oxblur, основное видео 16:9 помещается по центру.
   - *Smart Crop*: аналитическое выражение смещения X if(lt(t, T), X, ...) в фильтре crop.
3. **Оверлеи**:
   - Верхний хук-заголовок: drawtext в темной рамке в верхней трети.
   - Субтитры: желтый шрифт с черной обводкой в нижней трети.
   - Водяной знак: текст призыва к действию в самом низу.
4. **Аудио и скорость**:
   - Ускорение 1.03x (setpts=PTS/1.03 и tempo=1.03) для обхода Content ID.
   - Микширование дорожки диалогов и фоновой музыки через mix.
5. **Кодирование**: libx264, preset veryfast, crf 20-21, yuv420p, ac 192k.
