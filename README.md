# 🎬 VideoHook — AI-генератор вирусных вертикальных клипов 9:16 (Shorts / Reels / TikTok)

**VideoHook** — десктопное приложение и веб-интерфейс для автоматического мониторинга трендовых аниме, поиска культовых сцен, очистки видео от водяных знаков и генерации вирусных вертикальных роликов **9:16 (1080×1920)** для **YouTube Shorts, TikTok, Instagram Reels, VK Клипов и RuTube**, а также построения воронок трафика в **Telegram**.

---

## ✨ Основные возможности

### 1. 🔥 Радар трендов и база культовых моментов (`trends.py`)
- **Интеграция с AniList GraphQL API** в реальном времени (не требует API-ключей):
  - *«🔥 В тренде сейчас»*, *«🌟 Популярные (All-time)»*, *«🏆 Топ рейтинга»*.
- **База знаний культовых сцен (`ICONIC_MOMENTS_DB`)**:
  - Точные таймкоды, серии и поисковые запросы для топовых тайтлов (*Клинок, рассекающий демонов*, *Магическая битва*, *Атака титанов*, *Поднятие уровня в одиночку*, *Ван Пис*, *Человек-бензопила*, *Тетрадь смерти*, *Наруто* и др.).
  - Автоматическая генерация хук-заголовков и субтитров для удержания внимания с первых секунд.

### 2. 🌐 Мультиплатформенный загрузчик и парсер шортсов (`social_downloader.py`, `downloader.py`)
- Поиск и выкачивание целевых HD-фрагментов (1080p) через `yt-dlp` с **YouTube Shorts, TikTok, Instagram Reels, VK Видео/Клипов и RuTube** без необходимости скачивать гигабайтные сезоны целиком.
- Встроенный каталог проверенных вирусных клипов с русской озвучкой и субтитрами (`CURATED_VIRAL_SHORTS`).

### 3. 🧠 Автоопределение аниме и очистка водяных знаков (`anime_detector.py`, `watermark_remover.py`)
- **Распознавание тайтла (`anime_detector.py`)**: автоматическое определение названия аниме (RU/EN) по описаниям, тегам, именам персонажей и ключевым словам + фильтрация нерелевантного контента.
- **Удаление водяных знаков и аутро (`watermark_remover.py`)**:
  - Анализ временной дисперсии кадров через OpenCV для поиска статичных логотипов, плашек каналов и водяных знаков TikTok в углах кадра.
  - Автоматическое удаление вотермарок фильтром `delogo` / умным кропом и обрезка рекламных концовок (outro cards).

### 4. ✂️ Интерактивный видеоредактор и Smart Crop (`editor_window.py`, `smart_crop.py`)
- Полноценное окно нелинейного монтажа с видеопревью (`OpenCV`) и синхронным звуком (`pygame.mixer`).
- **Инструмент «Ножницы»** (`S` / `Ctrl+K`), отмена действий (`Ctrl+Z`), интерактивный таймлайн с раскадровкой (Filmstrip) и разметкой сегментов *«Оставить / Вырезать»*.
- **Saliency Smart Crop 9:16**: покадровое отслеживание главного персонажа в кадре для автоматического динамического центрирования при переводе из 16:9 в 9:16.

### 5. 🚀 Движок рендеринга и Telegram-воронки (`clipper.py`, `antigravity_bridge.py`, `viral_tg.py`)
- **Два режима вертикального кадра 9:16**:
  - `Blurscreen` — кинематографичный размытый фон 9:16 с четким кадром 16:9 по центру.
  - `Fullscreen` — полноэкранный вертикальный кроп с поддержкой Smart Crop.
- **Трендовая стилизация и защита от Content ID**:
  - Верхние хук-баннеры, динамические субтитры, наложение фоновой музыки (Phonk, Epic Orchestral, Lo-Fi или свой трек) с микшированием громкости, ускорение `1.03x` (`setpts` / `atempo`).
- **Генератор конверсионных воронок в Telegram (`antigravity_bridge.py`, `viral_tg.py`)**:
  - Готовые шаблоны триггеров (*Эпичный бой*, *Клиффхэнгер/Интрига*, *Разбор/Пасхалки*, *Саундтрек-эдит*) и брендированные плашки с призывом перейти в Telegram-канал.

### 6. 🖥️ Два интерфейса: Десктоп (CustomTkinter) + Браузерный Web UI
- **Desktop GUI (`main.py` / `gui.py`)**: нативное темное приложение на `CustomTkinter` с вкладками *«🔥 Радар трендов»*, *«🌐 Вирусные Shorts / Соцсети»* и *«📁 Моя библиотека»*.
- **Web UI (`browser_test.py`)**: интерактивная локальная веб-панель с живым видеоплеером, поиском клипов, очисткой вотермарок и генерацией Telegram-воронок прямо в браузере.

## 🛠 Технологический стек

- **Язык**: Python 3.10+
- **GUI & Web**: `CustomTkinter`, `tkinter.Canvas`, встроенный `ThreadingHTTPServer` (Web UI)
- **Видео и компьютерное зрение**: `FFmpeg` (`libx264`, `filter_complex`), `OpenCV` (`cv2`), `Pillow`, `NumPy`
- **Аудио и анализ пиков**: `pygame.mixer`, RMS-анализатор звукового давления (`analyzer.py`)
- **Сеть и парсинг**: `yt-dlp`, `requests` (AniList GraphQL API)

## ⚡ Быстрый старт

### 1. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 2. Запуск десктопного приложения
Дважды кликните по **`run_app.bat`** (Windows) или выполните в терминале:
```bash
python main.py
```

### 3. Запуск интерактивного веб-интерфейса
Дважды кликните по **`run_browser_test.bat`** или выполните:
```bash
python browser_test.py
```

### 4. Сборка в автономный `.exe` (PyInstaller)
```bash
pyinstaller VideoHook.spec
```

## 📂 Архитектура проекта

| Файл | Назначение |
| :--- | :--- |
| `main.py` | Точка входа десктопного приложения |
| `gui.py` | Главное окно CustomTkinter (Радар трендов, Соцсети, Локальная библиотека) |
| `editor_window.py` | Интерактивный видеоредактор с таймлайном, ножницами, раскадровкой и аудиопревью |
| `browser_test.py` | Локальный веб-сервер и браузерный UI для теста, скачивания и рендера |
| `clipper.py` | Ядро рендеринга FFmpeg (9:16 Blurscreen/Fullscreen, субтитры, музыка, склейка) |
| `smart_crop.py` | Покадровый трекинг салиентности для умного центрирования кадра 9:16 |
| `trends.py` | Клиент AniList GraphQL API и база знаний культовых моментов `ICONIC_MOMENTS_DB` |
| `social_downloader.py` | Мультиплатформенный загрузчик и парсер (Shorts, TikTok, Reels, VK, RuTube) |
| `downloader.py` | Модуль быстрого поиска и скачивания целевых сцен через `yt-dlp` |
| `anime_detector.py` | Интеллектуальный детектор аниме-тайтлов по метаданным, тегам и персонажам |
| `watermark_remover.py` | Автоматический детектор и клинер водяных знаков и рекламных концовок |
| `antigravity_bridge.py` | Генератор вирусных хуков, описаний и воронок конверсии в Telegram |
| `viral_tg.py` | Автоматический рендер брендированных плашек и Telegram CTA поверх 9:16 видео |
| `analyzer.py` | Анализатор звуковых пиков (RMS + NMS) для автонарезки длинных локальных видео |
| `hotkeys.py` | Универсальный менеджер горячих клавиш для любой раскладки клавиатуры |
| `assets/music/` | Встроенные фоновые треки (`phonk_bass.mp3`, `epic_orchestral.mp3`, `lofi_chill.mp3`) |
