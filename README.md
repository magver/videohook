# VideoHook 2.0 — конвейер вирусных аниме-шортсов

Находит самые сильные и самые просматриваемые моменты аниме, монтирует вертикальный ролик 9:16 с авторской подложкой,
отдаёт его на доработку агенту **Google Antigravity (Gemini 3.8 Flash)**, забирает результат, пишет описания и
публикует в **YouTube Shorts, TikTok и Instagram Reels**.

```
Моменты ─► Источник + лучший отрезок ─► Монтаж 9:16 ─► Antigravity ─► Описания ─► Публикация
 (база,      (YouTube «самые пересмат-    (подложка,      (агент на      (Gemini)     (YouTube API,
  тренды,     риваемые», громкость,        тексты, луп,     Gemini 3.8                  TikTok API,
  Gemini)     динамика, Gemini-анализ)     музыка)          Flash)                      ассистент)
```

## Запуск

```bash
pip install -r requirements.txt
python main.py            # окно программы
python main.py --browser  # интерфейс в браузере
```
VideoHook — настольная программа: интерфейс открывается в собственном окне (Edge WebView2, есть в Windows 10/11),
локальный сервер работает внутри того же процесса. Закрытие окна завершает программу; если идут задачи, программа спросит.
На Windows — двойной клик по `run_app.bat` или по собранному `VideoHook.exe` (`pyinstaller VideoHook.spec` → `dist/`).
Лог работы — `workspace/data/videohook.log`.
Все рабочие данные (исходники, рендеры, задачи агента, настройки, токены) — в папке `workspace/` рядом с программой.

## Интерфейс

| Раздел | Что делает |
| --- | --- |
| **Сводка** | воронка по стадиям, список «что сделать дальше», состояние базы моментов и подключений |
| **Моменты** | тренды AniList, база моментов (36 тайтлов, 68+ сцен), свой момент, ролик по ссылке |
| **Студия** | выбор отрезка на таймлайне с подсказками (пересмотры / звук+динамика / Gemini), подложка, хук, подпись, музыка, эффекты → рендер |
| **Antigravity** | задачи агента: статус в реальном времени, промпт в один клик, папка задачи, «взять черновик» |
| **Публикация** | описания под каждую площадку со счётчиками лимитов, загрузка через API или ассистент |
| **Настройки** | канал, Gemini, Antigravity, монтаж, YouTube/TikTok |

**⚡ Автопилот** — берёт N свежих моментов из трендовых тайтлов и прогоняет весь конвейер без участия человека.

## Самопополняемая база моментов

* Сид: `data/moments.json` (редактируемый JSON: тайтлы, алиасы, студии, сцены, хуки, настроение).
* Пользовательская база: `workspace/data/moments_user.json` — сюда пишутся новые моменты и учёт использования.
* Использованный момент (по нему создан клип) уходит из выдачи «свежих».
* Когда у тайтла остаётся меньше 3 свежих моментов, в фоне запускается пополнение:
  1. **Gemini** предлагает новые реальные сцены, которых ещё нет в базе;
  2. **YouTube** — самые просматриваемые ролики по тайтлу;
  3. жанровые шаблоны — только если свежих не осталось совсем.
* Тайтлы из трендов AniList регистрируются в базе автоматически.

## Как выбирается лучший отрезок

Сигналы объединяются, совпадения усиливают друг друга:
* **YouTube «Самые пересматриваемые»** (heatmap из yt-dlp) — реальные данные зрителей. Для длинных видео скачивается фрагмент с запасом ±45 c вокруг пика;
* **громкость (RMS) и плотность смены сцен** — кульминации и динамичный монтаж;
* **Gemini через Antigravity** смотрит видео, раскадровку и слушает звук: выбирает законченную сцену
  (завязка → кульминация → развязка), при длинной сцене собирает её из 2–4 частей без затянутой середины,
  отмечает ударные моменты, момент замедления и пишет русские субтитры.

Границы отрезка всегда подтягиваются к естественным точкам: начало — к склейке или паузе перед первой репликой,
конец — к паузе после последней фразы (реплика и реакция не обрываются). Длина — сколько нужно сцене, до 58 c.

## Монтаж и звук

* Основа — **родной звук сцены** (компрессия и подъём низа); музыка из библиотеки — только по выбору.
* Панч-зумы, вспышки и низкий «удар» по звуку на ударных моментах; замедление кульминации 0.5x.
* Переходы между частями по настроению (вспышка, через чёрный, растворение, зум, сдвиг) со звуком «вжух».
* **Русские субтитры**: ручные русские с YouTube → автоперевод YouTube → перевод оригинальных субтитров через Gemini;
  при анализе Gemini расшифровывает и переводит речь сам. Источник с **русской озвучкой** ищется в первую очередь.

## Подложка и авторские права

Шаблоны: `cinema` (размытый фон + кадр), `fullscreen` (умный кроп по персонажу), `frame` (фирменная рамка),
`commentary` (кадр + авторский комментарий). Всегда добавляются: хук, подпись/реплики, подпись канала,
прогресс-бар и **кредит правообладателю** («Аниме: … · © студия · фан-обзор»). Длина ограничена (по умолчанию до 58 c).
Программа не удаляет чужие водяные знаки и не применяет трюки обхода Content ID. Трансформирующее
оформление снижает риски, но не заменяет лицензию: решение о допустимости публикации остаётся за автором канала.

## Обмен с Antigravity

Для каждого ролика создаётся папка `workspace/antigravity/<задача>/`:

```
BRIEF.md                 задание агенту (структура хука, направление по настроению, тех. требования, контракт результата)
job.json                 все параметры машиночитаемо
input/source_cut.mp4     чистый фрагмент без надписей
input/draft_9x16.mp4     черновик VideoHook
input/storyboard.jpg     раскадровка 4×4
input/music, input/fonts
output/                  ← агент кладёт final.mp4, cover.jpg, result.json (+ status.txt по ходу работы)
```
VideoHook сам находит запущенный Antigravity (или запускает его), подключается к его language server и создаёт
диалог через `agentapi new-conversation --model=flash` — ручная вставка промпта не нужна.
Если нет, промпт копируется в буфер и его нужно вставить в Antigravity. В обоих случаях VideoHook сам следит за `output/`
и импортирует готовый ролик вместе с описаниями.

## Google AI Pro — что используется

| Возможность | Где |
| --- | --- |
| Antigravity (основной канал: мощнее модель, лимиты подписки) | подбор моментов, анализ видео и раскадровки, описания — задачи через файлы |
| Gemini API (ключ из [AI Studio](https://aistudio.google.com/apikey)) | запасной канал, если Antigravity недоступен |
| Antigravity + Gemini 3.8 Flash | финальный монтаж: зумы, ритм под бит, субтитры, луп, обложка |

## Публикация

* **YouTube Shorts** — YouTube Data API v3: укажите `client_secret.json` (OAuth-клиент «Приложение для ПК»)
  и нажмите «Подключить YouTube». Загрузка в один клик, приватность настраивается.
* **TikTok** — Content Posting API (`video.upload`): ролик уходит во «Входящие», подпись копируется в буфер.
* **Instagram Reels** — ассистент: подпись копируется в буфер, файл выделяется в проводнике, открывается instagram.com.
* Без API любая площадка работает через ассистента. Включите «Автопубликацию», чтобы готовые ролики уходили сами.

## Структура

```
main.py            запуск
vh/core.py         пути, настройки, FFmpeg, фоновые задачи
vh/moments.py      база моментов, пополнение, тренды AniList
vh/discovery.py    поиск источников, heatmap, анализ звука/сцен, скачивание фрагментов
vh/gemini.py       ИИ-задачи и промпты (Antigravity → Gemini API)
vh/agbridge.py     подключение к запущенному Antigravity (agentapi), задачи с ответом в файле
vh/render.py       рендер 9:16, ASS-оверлеи (libass), умный кроп, луп, обложка
vh/antigravity.py  папка задачи, запуск агента, отслеживание, импорт
vh/publish.py      описания, YouTube/TikTok API, ассистент
vh/pipeline.py     шаги конвейера и автопилот
vh/server.py       REST API + статика (только 127.0.0.1)
vh/desktop.py      окно программы (pywebview / WebView2)
web/               интерфейс (HTML/CSS/JS без сборки)
data/moments.json  сид базы моментов
tests/             pytest: офлайн-конвейер целиком, API, база
```

Тесты: `pip install -r requirements-dev.txt && pytest`.
Шрифт Rubik ExtraBold распространяется по лицензии SIL OFL 1.1 (`assets/fonts/OFL.txt`).
